# Atelier Bonheur

App web installable : petits gestes, gratitude, rêves (méthode WOOP), ancrage, musique et bilan.

**Installer sur iPhone** : ouvrir l'adresse dans Safari → Partager → « Sur l'écran d'accueil ».

Les données restent sur le téléphone (aucun serveur). Onglet Bilan → « Mes données » pour sauvegarder ou restaurer.

Fichiers générés par `build_pwa.py` depuis le dépôt privé — ne pas modifier à la main.
